### 🎯 Syllabus Topics
- **OSI Model** — 7 layers, layered architecture, encapsulation, peer-to-peer processes
- **TCP/IP Protocol Suite** — Application, Transport, Internet, Network Access layers
- **Network Criteria** — Performance, Reliability, Security
- **Transmission Media** — Guided vs Unguided, Twisted Pair, Coaxial, Optical Fiber
- **Types of Networks** — PAN, LAN, MAN, WAN (definitions, differences, examples)
- **Topologies** — Bus, Star, Ring, Mesh (comparison, advantages, disadvantages)
- **Collision Handling** — CSMA/CD, why collisions occur in Bus topology
- **Layered Tasks** — Sender, Receiver, Carrier roles
- **Protocols & Standards** — Ethernet, Fast Ethernet, Metro Ethernet
