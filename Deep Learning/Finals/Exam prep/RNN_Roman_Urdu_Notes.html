1. Sequential Data kya hota hai?
SLIDES 5–10
Definition: Sequential data woh data hai jisme har element ek specific order mein hota hai aur elements aapas mein depend kartay hain. Normal tabular data ki tarah nahi hota jahan rows independent hoti hain.
1
Do key properties: (a) Elements ek specific order mein atay hain, (b) Elements ek doosre par depend kartay hain — yaani aik element ka matlab doosray ke baghair samajhna mushkil hai.
2
Sequence ki examples: Text documents (sentences), audio waveforms aur spectrograms, images (pixel rows), time-series data (stock market, brain waves, air temperature, radio waves).

Sequence ke 3 Types of Applications

Type Input Output Example
One-to-Many Fixed-size (ek cheez) Sequence (kai cheezain) Image Captioning — ek tasweer dou, caption likha aayega
Many-to-One Sequence (kai cheezain) Fixed-size (ek cheez) Sentiment Analysis — movie review dou, "positive/negative" aayega

3. Feedforward Network vs RNN — Farq kya hai?
SLIDES 13–16
❌ Feedforward Network (Purana)
  • Har layer sirf agle layer ko input deti hai
  • Koi loop nahi — data sirf aage jaata hai
  • Problem 1: Bahut saray parameters
  • Problem 2: Input/output size fixed hoti hai
  • Problem 3: Koi memory nahi — weights independently seekhay jaatay hain, pichla data yaad nahi rehta
✅ Recurrent Network (Naya)
  • Har layer previous layer + previous time step ka output bhi leta hai
  • Loop hota hai — "time-delayed connections"
  • Memory hoti hai — puraani info yaad rehti hai
  • Variable length sequences handle kar sakta hai
  • Shared weights — kam parameters
Main Idea (yaad rakho!): RNN mein ek hidden state hota hai jo past ki information store karta hai. Yeh hidden state har time step par update hota rehta hai.

4. RNN ka Mathematical Structure
SLIDES 15–26
Core Recurrence Formula st = fm( st-1 , xt )
s
st = Naya hidden state (abhi ka) — New State
s
st-1 = Purana hidden state (pichle waqt ka) — Old State
x
xt = Abhi ka input — Input at current time step
f
fm = Function jisme model parameters (m = model parameters) hain — same function har time step par lagaya jaata hai. Isliye iska naam "Recurrent" hai!
Forward Pass Formula (Practical RNN) ht = tanh( Whh · ht-1 + Wxh · xt + bias )
W
Wxh = Input ko hidden state se jodne wala weight matrix (green)
W
Whh = Hidden state ko agle hidden state se jodne wala weight matrix (orange)
W
Why = Hidden state se output nikalne wala weight matrix (blue)
🔑 Key Insight: Tamam layers ke liye same weights (U, V, W) use hotay hain! Layers ke beech sirf xt (input) alag hota hai. Isliye RNN mein FNN ke muqablay bahut kam parameters hotay hain.
Unfolding kya hai? RNN ka loop khol ke use time ke saath phailaao — toh woh ek deep feedforward network ban jaata hai jisme shared weights hotay hain. Yeh bahut important concept hai!

5. RNN ke Fayde (Advantages)
SLIDES 26–29
1
Memory: Previous hidden state use karke past ki information yaad rakhta hai — FNN mein yeh mumkin nahi tha kyunki weights independently seekhay jaatay thay.
2
Kam Parameters: Sab time steps ke liye same weights share hotay hain — isliye FNN ke muqablay parameters ki tadaad bahut kam hoti hai.
3
Variable Length: Theortically kisi bhi length ki sequence handle kar sakta hai — sirf time steps unfold/fold karo. Short ya long sequence, dono kaam kartay hain.
4
Dynamic Memory: Past information kitni der yaad rakhi jayegi yeh model ki weights aur data decide kartay hain — koi fixed duration nahi. Yeh FNN se bahut different hai.

7. Training Approach: BPTT
SLIDES 36–43
Training ki method: Back-Propagation Through Time (BPTT) — yeh wohi generalized gradient derivation hai jo hum pehle seekh chukay hain, sirf time ke saath unfolded network par apply hota hai.

Yeh process baar baar repeat hoti hai jab tak stopping criterion poori na ho:

🔵 Step 1: Forward Pass

Training data ko unfolded RNN ke through propagate karo — output nikalte jao. Yeh forward direction mein hota hai.

🟢 Step 2: Error Quantification

Model ki predictions aur asli data mein kitna farq hai? Loss function use karke measure karo.

Many-to-Many task mein Cross Entropy Loss use hoti hai — har time step par loss calculate karo phir sab jodo.

🔴 Step 3: Backward Pass

Har model parameter (U, V, W) ke liye gradients calculate karo.

Important! Weight sharing ki wajah se: gradients ko tamam time steps ke liye sum karo. Ek weight ki gradient = har time step par us weight ki gradient ka sum.

⚪ Step 4: Update Parameters

Calculated gradients use karke har parameter update karo — gradient descent se.

9. Learning Problem: Vanishing Gradient
SLIDES 49–51
Problem: RNN long-term dependencies seekhne mein fail ho jaata hai — matlab purani information (bahut pehle waala input) ko yaad nahi rakh paata.

Example samjho

"In 2004, I started college" — yahaan "2004" shuroo mein hai aur baad mein uski zaroorat hai. Agar sequence lamba ho toh RNN "2004" bhool jaata hai.

!
Kyun hota hai yeh? RNN mein unfolding ke baad same weights baar baar multiply hotay hain. Agar weight 1 se chhota ho (jaise 0.8), toh 0.8 × 0.8 × 0.8 × ... = 0 ki taraf jaata hai — Yahi Vanishing Gradient hai!
!
Exploding Gradient bhi hota hai: Agar weight 1 se bada ho, toh gradients bahut zyada barhte hain — especially ReLU activation ke saath.
!
Yeh FNN aur CNN mein itna bura kyun nahi? Unme alag alag weights hotay hain har layer mein. RNN mein same weights repeatedly multiply hotay hain — isliye problem zyada severe hoti hai.
Vanishing Gradient

Gradients → 0 ho jaatay hain. Neurons "die" kar jaatay hain (0 gradient). Purani information model nahi seekh paata.

Solution

tanh activation + Gates (LSTM/GRU) use karo. Gates control kartay hain kaunsi information yaad rakhni hai aur kounsi bhoolni hai.

10. Gated RNN #1: LSTM
SLIDES 54–58
LSTM = Long Short-Term Memory — 1997 mein aaya. Yeh basic RNN ka upgraded version hai jo long-term dependencies yaad rakh sakta hai.

2 States Forward Pass Kartay Hain

Hidden State (ht)

Basic RNN ki tarah — short-term memory. Output nikalne ke liye use hota hai.

Cell State (st) — NEW!

Long-term memory! Bahut lamba waqt information retain kar sakta hai. Yeh LSTM ki asli power hai.

3 Gates — Yeh LSTM ki Pehchaan Hain!

i
Input Gate (σ): Decide karta hai — naya input kitna cell state mein add karna hai? (0 = kuch nahi, 1 = sab kuch)
f
Forget Gate (σ): Decide karta hai — purani cell state ki kitni information bhoolni hai? (0 = sab bhool jao, 1 = sab yaad rakho). Yeh most important gate hai!
o
Output Gate (σ): Decide karta hai — cell state ki kitni information output mein deni hai?
Cell State Update Formula st = st-1 · f + g · i
→
Yahan addition (+) ka use hota hai multiplication ki jagah — isliye gradient time ke saath aasaani se flow karta hai (vanishing gradient fix hota hai!)
Gate kyun bolte hain? Gates mein sigmoid (σ) function use hota hai jiska output 0 se 1 ke beech hota hai — bilkul darwaze ki tarah: 0 = band, 1 = khula. Isliye naam "gate" hai!
Forget Gate ValueKya hota hai?
f = 0Pura purana cell state bhool jao (past discarded)
f = 1Pura purana cell state yaad rakho (past retained)

11. Gated RNN #2: GRU (Gated Recurrent Unit)
SLIDE 59
GRU = LSTM ka simplified version — 2014 mein aaya. Yeh LSTM se zyada simple hai aur aksar same performance deta hai.
✓
LSTM vs GRU ka farq: LSTM mein 2 separate states hotay hain (hidden + cell). GRU mein sirf ek hidden state hota hai jo dono kaam karta hai.
✓
Single gate: GRU mein ek single gate dono kaam karta hai — (1) forgetting factor aur (2) hidden units update karna. LSTM mein yeh alag alag hain.
✓
Reset gate (r[t]): Kitna purana hidden state consider karna hai.
✓
Update gate (z[t]): New hidden state calculate karne ke baad — kitna naya aur kitna purana mix karna hai? (complementary: z aur 1-z)
LSTM

3 gates (input, forget, output) + 2 states (h, s). Zyada complex, zyada parameters, zyada control.

GRU

2 gates (reset, update) + 1 state (h). Simple, fewer parameters, faster training. Often similar performance.

1
Sequence kya hai? Aisa data jisme order matter karta hai aur elements dependent hotay hain (text, audio, time-series).
2
RNN ka core idea? Hidden state use karo past ki information yaad rakhne ke liye: st = fm(st-1, xt).

RNN vs FNN? RNN mein loop hai + memory hai + variable length sequences + shared weights. FNN mein koi memory nahi.

Unfolding? RNN ka loop khol do toh ek deep FNN ban jaata hai jisme shared weights hotay hain.
5
Training method? Back-Propagation Through Time (BPTT) — weight sharing ki wajah se gradients ko sab time steps par sum karo.
6
Vanishing Gradient? Same weights baar baar multiply hotay hain — gradients 0 ho jaatay hain — RNN purani information bhool jaata hai.
7
LSTM ka solution? Cell state + 3 gates (input, forget, output) — addition operation ki wajah se gradient flow theek rehta hai. 1997 mein aaya.
8
GRU? LSTM ka simplified version — sirf 2 gates (reset, update) aur 1 state. 2014 mein aaya. Aksar LSTM jitna hi acha kaam karta hai.
