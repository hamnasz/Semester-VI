Topic 1

RNN se Machine Translation — Bunyaadi Masla

RNN mein ek Encoder hota hai jo input (jaise English) ko process karta hai aur ek hidden state h banata hai.
Decoder us hidden state ko le kar output (jaise Spanish) generate karta hai, ek word at a time.
Encoder: hₜ = fW(xₜ, hₜ₋₁)  |  Decoder: sₜ = gU(yₜ, sₜ₋₁)
Masla: Poori input sequence ek fixed-size vector (bottleneck) se guzarti hai — lambi sentences ke liye yeh kaafi nahi hota.
Chhota hal: Context vector c = h₄ add karo aur har decoder step mein use karo — lekin pھir bhi bottleneck hai.
Topic 2

Attention Mechanism — Asli Hal (Bahdanau 2015)

Idea: Decoder ke har step par ek naya, alag context vector banao. Pehle wala fixed tha — yeh dynamic hai.
Har decoder state sₜ₋₁ ko har encoder hidden state hᵢ se compare karo ek alignment score eₜ,ᵢ nikalne ke liye (MLP use hoti hai).
Scores ko Softmax se guzaaro — yeh attention weights aₜ,ᵢ bante hain (sab mil ke 1 hote hain).
cₜ = Σᵢ aₜ,ᵢ · hᵢ    (weighted sum of encoder states)
Intuition: "estamos" translate karte waqt, attention weights h₁ (we) aur h₂ (are) par zyada hoti hain — model wahi "dekhta" hai jo zaroori ho.
Yeh poora process differentiable hai — attention weights ko directly train nahi karte, backprop sab kuch seekh leta hai.
Topic 3

Attention Layer — General Form (Query, Key, Value)

Attention ko generalize kiya gaya 3 cheezein mein: Query (Q), Key (K), aur Value (V).
Query = "main kya dhoondh raha hoon?"  |  Key = "mere paas kya hai?"  |  Value = "actual information"
K = X·Wₖ  |  V = X·Wᵥ  |  E = QKᵀ / √Dq  |  A = softmax(E)  |  Y = AV
Dot product similarity use hoti hai (MLP ki jagah) — zyada fast aur parallelizable hai.
Scaling (√Dq) isliye karte hain ke zyada dimensions mein dot products bahut bade ho jaate hain — softmax saturate ho jata hai.
Topic 4

Self-Attention Layer

Jab Q, K, V teeno ek hi input X se bante hain — isko Self-Attention kehte hain.
Har input vector apne aap ko aur baaki sabse compare karta hai — "sentence mein context samajhna".
Q = X·Wq  |  K = X·Wₖ  |  V = X·Wᵥ
Permutation Equivariant: Agar input ka order badlo, toh output bhi usi tarha badlega — f(s(x)) = s(f(x)). Matlab model naturally order nahi jaanta.
Positional Encoding: Isliye position information alag se add karte hain input vectors ke saath — yeh learned table bhi ho sakti hai ya fixed sinusoidal function.
Masked Self-Attention: Language modeling mein future tokens "dekhne" se rokne ke liye future positions ko -∞ se mask karte hain.
Multi-Head Attention: H parallel attention heads chalao, alag Wq/Wₖ/Wᵥ ke saath, phir concatenate karo — zyada rich representation milti hai.
Topic 5

RNN vs 1D Conv vs Self-Attention — Comparison

RNN
✓ Long sequences handle karta hai
✗ Parallel nahi chal sakta
✗ Sequential computation
1D Convolution
✓ Highly parallel
✗ Long sequences ke liye kaafi layers chahiye
✗ Limited receptive field
Self-Attention
✓ Ek hi layer mein sab kuch dekhta hai
✓ Highly parallel
✗ Memory bahut zyada use karta hai (O(n²))
Topic 6

The Transformer (Vaswani et al, 2017 — "Attention is All You Need")

Ek Transformer Block mein yeh hota hai: Self-Attention → Layer Norm + Residual → MLP → Layer Norm + Residual
Residual Connection (+): Input ko output mein add karte hain — deep networks mein training asaan hoti hai, gradients theek se flow karte hain.
Layer Normalization: Har vector ko normalize karo — training stable rehti hai. (Batch norm se different — yeh per-sample kaam karta hai)
Self-Attention sirf woh jagah hai jahan vectors aapas mein "baat karte" hain — MLP aur LayerNorm independently har vector par kaam karte hain.
Kaafi Transformer Blocks ko stack karo — yahi poora Transformer model hai. Encoder-Decoder architecture use hoti hai machine translation ke liye.
GLUE Benchmark: NLP tasks par Transformers (BERT, RoBERTa etc.) ne human baseline ko bhi peeche chhod diya.
Topic 7

Transformers Sirf Text Ke Liye Nahi — ViLBERT

Transformers ko vision + language dono ke liye use kar sakte hain — ViLBERT (Lu et al, 2019) iska example hai.
Image ko Faster R-CNN se process karo — object regions ki features nikalo. Text ko alag transformer stream mein daalo.
Dono streams ek Multimodal Transformer mein "cross-attention" ke zariye interact karti hain.
Kaam aata hai: Visual Question Answering (image ke baare mein sawaal), Image Captioning, Visual Grounding etc.
