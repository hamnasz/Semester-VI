🔑 SIFT (1999)
  • Full: Scale Invariant Feature Transform
  • Rotation Invariant ✓   Scale Invariant ✓
  • Excellent feature matching
  • Limitation: Computationally expensive
🚀 SURF (2006)
  • Full: Speeded Up Robust Features
  • Faster version of SIFT
  • Scale & Rotation Invariant
🚶 HOG (2005)
  • Full: Histogram of Oriented Gradients
  • Uses edge directions & gradients
  • Famous: Pedestrian Detection
📏 Sobel Operator (1968)
  • Two 3×3 kernels: Sobel X and Sobel Y
  • Detects horizontal and vertical edges
  • Limitation: Sensitive to noise
Gx = SobelX * I
Gy = SobelY * I
G = √(Gx² + Gy²) ← Edge Strength
📊 Otsu Thresholding (1979)
  • Automatic threshold selection — no manual input
  • Converts image → Foreground & Background
  • Input: Histogram — Goal: Maximize Between-Class Variance
  • Application: Document scanning, OCR

Otsu finds threshold T automatically by maximizing variance between foreground and background classes.

Image Localization & Object Detection

📦 Bounding Box Formats
Format 1 — Center + Size
(bx, by, bw, bh)
bx = Center X   by = Center Y
bw = Width    bh = Height
Format 2 — Corner Coordinates
(xmin, ymin, xmax, ymax)
xmin=Left   ymin=Top
xmax=Right   ymax=Bottom
🧠 Localization Architecture
  • CNN backbone extracts features
  • Split into two heads simultaneously
📏 IoU Formula
IoU = Area of Overlap
      ──────────────────
      Area of Union

Range: 0 ≤ IoU ≤ 1
IoU > 0.5 → Good Prediction
  • IoU = 0 → No overlap at all
  • IoU = 1 → Perfect prediction
📉 Loss Functions
  • Classification: Softmax + Cross Entropy Loss
  • Regression: L2 Loss (MSE) or Smooth L1 Loss
  • Total Loss: Classification + Localization Loss
🐢 Two-Stage Detectors
  • Stage 1: Find candidate boxes (region proposals)
  • Stage 2: Classify objects in those regions
  • ✅ Highly Accurate   ❌ Slow
  • Examples: R-CNN, Fast R-CNN, Faster R-CNN
  • Memory Trick: Detect First, Classify Later
⚡ One-Stage Detectors
  • Detect + Classify in a single forward pass
  • No separate region proposal stage
  • ✅ Very Fast   ✅ Real-Time   ❌ Less accurate on small objects
  • Examples: YOLO, SSD
  • Memory Trick: Everything At Once

Localization = Classification + Bounding Box Regression — always performed simultaneously using Multi-Task Learning with a combined loss function.

R-CNN — Region-Based CNN (2014)

🎯 Purpose & Core Idea
  • Introduced by Ross Girshick (2014)
  • Revolutionized deep learning-based object detection
  • Replaced HOG, SIFT, and Sliding Window methods

⚡⚡ Faster R-CNN — The Big Jump

Replace Selective Search with a Neural Network (RPN) — fully learnable region proposals

Two Main Components:
A. Shared CNN Backbone
  • Extracts Feature Maps shared by RPN and Detector
  • Run only once — very efficient
B. Region Proposal Network (RPN)
  • Small neural network sliding over feature map
  • Predicts Objectness Score + Bounding Boxes
  • Completely replaces Selective Search

YOLO — You Only Look Once

📌 Core Philosophy
  • Introduced by Joseph Redmon (2016)
  • Single-Stage Object Detector
  • Image processed only ONCE
  • Detection = Regression Problem
  • No Region Proposals, No Selective Search, No RPN
  • Output: BBoxes + Class Probabilities + Confidence
Input Image → CNN → Output Tensor (All in ONE forward pass)
⚙️ Working Pipeline
1
Grid Division (S×S)
Image → 7×7 grid. Object belongs to cell containing its center point
2
BBox Prediction
Each cell predicts B=2 boxes with (x, y, w, h, confidence)
3
Class Prediction
Each cell predicts C=20 classes (PASCAL VOC)
🧮 Output Tensor Formula
S × S × (B×5 + C)

S = 7 (grid size)
B = 2 (boxes per cell)
C = 20 (classes)

= 7 × 7 × (2×5 + 20)
= 7 × 7 × 30
🚫 Non-Maximum Suppression (NMS)
  • Removes duplicate bounding boxes
  • Select highest confidence box
  • Remove highly overlapping boxes (by IoU)
  • Result: 1 Object → 1 Box
✅ Advantages
  • Extremely fast — 45-155 FPS
  • Real-Time detection capability
  • Single neural network (End-to-End)
  • Global image context → fewer background errors
  • Can process videos live
❌ Limitations
  • Struggles with small objects
  • Difficulty with dense crowds
  • Limited boxes per grid cell
  • Localization less accurate than Faster R-CNN
  • Multiple nearby objects may be missed

U-Net — Semantic Segmentation (2015)

📌 Core Concept
  • Proposed by Olaf Ronneberger (2015)
  • Designed for Biomedical Image Segmentation
  • Task: Assign a class to every single pixel
  • Architecture shaped like letter U
  • Applications: Tumor detection, road segmentation, cell segmentation

Bottleneck

🏗 Architecture Flow
⭐ Skip Connections — Key Strength
  • Problem: Max Pooling loses spatial location info
  • Solution: Copy encoder features directly to decoder
  • Also called Copy-and-Crop mechanism
  • ✅ Preserve fine details (tumor boundaries, edges)
  • ✅ Better localization & higher accuracy
🎲 Dice Loss
Dice = 2|A∩B| / (|A| + |B|)

A = Ground Truth Mask
B = Predicted Mask

Dice Loss = 1 − Dice Score
  • Why needed? Medical data: 99% background, 1% tumor → class imbalance
  • Dice Score = 0 → No overlap
  • Dice Score = 1 → Perfect match

Encoder: Conv→ReLU→MaxPool (H↓, W↓, C↑)  |  Bottleneck: Deepest, most abstract  |  Decoder: UpConv→Concat→Conv (H↑, W↑, C↓)  |  Output: 1×1 Conv → pixel-wise class labels

SegNet — Semantic Segmentation (2015)

📌 Key Facts
  • Developed at University of Cambridge (2015) — Vijay Badrinarayanan
  • Deep Encoder-Decoder architecture
  • Primary use: Autonomous Driving & Robotics
  • Encoder based on VGG-16 (first 13 conv layers)
  • Key Innovation: Stores pooling indices instead of full feature maps
⭐ Max Pooling Indices — The Big Idea
U-NET
  • Transfers full feature maps
  • Very high memory usage
  • Best boundary accuracy
SEGNET
  • Stores only pooling locations
  • ~2 bits per 2×2 window
  • Very low memory usage

SegNet: Memory Efficient → suitable for embedded systems, robotics, self-driving cars

GANs — Generative Adversarial Networks (2014)

💡 Core Concept
  • Introduced by Ian Goodfellow (2014)
  • Adversarial game between 2 networks
  • Type: Zero-Sum / Minimax Game
  • Analogy: Art Forger vs Expert
  • Goal: Generate realistic synthetic data

Nash Equilibrium: D(x) = 0.5 — Discriminator completely confused, cannot distinguish real from fake

🏗 Architecture
🔥 Training Challenges
1
Mode Collapse
G generates same image repeatedly — no diversity
2
Vanishing Gradient
D too strong → G gets no learning signal
3
Non-Convergence
Loss oscillates continuously — never stabilizes
🎯 GAN Variants
  • DCGAN (2015): Uses CNN layers, more stable training
  • cGAN: Conditional — Noise + Label → controlled output
  • CycleGAN: Image translation (Horse→Zebra, Day→Night) — no paired data
📊 Minimax Objective Function
min_G max_D V(D,G) =
E[log D(x)] ← Discriminator wants real → 1
+ E[log(1 − D(G(z)))] ← Discriminator wants fake → 0

Generator Minimizes → wants D(G(z)) → 1 (fool D)
Nash Equilibrium when D(x) = 0.5

Paging & Segmentation — OS Memory Management

Purpose of Memory Management: Efficient RAM utilization, address translation, memory protection, process isolation, and memory sharing.

📄 PAGING — Physical View
  • Process divided into fixed-size Pages
  • RAM divided into fixed-size Frames
  • Page Size = Frame Size (typically 4 KB)
  • Page → Logical block  |  Frame → Physical block
Logical Address Format
(p, d)
p = Page Number
d = Offset (Displacement)
Address Translation
1

2

3
Physical Address = (f, d)
TLB (Translation Lookaside Buffer)
TLB HIT
  • Frame found fast
  • 1 memory access
TLB MISS
  • Search Page Table
  • 2 memory accesses
EAT = α(TLB + Mem) + (1−α)(TLB + 2×Mem)
α = TLB Hit Ratio
📑 SEGMENTATION — Logical / User View
  • Program divided into logical, variable-size Segments
  • Matches programmer's view of memory
  • Examples: Main program, Functions, Stack, Heap, Libraries

  • Valid (V): Page belongs to process — legal access

image = cv2.imread("image.jpg", 0)

_, segmented = cv2.threshold(
  image, 127, 255, cv2.THRESH_BINARY
)

cv2.imshow("Segmented Image", segmented)
cv2.waitKey(0)

Conclusion: Thresholding is a simple and efficient segmentation technique. Computationally inexpensive and widely used in document processing, medical imaging, industrial inspection, and object detection tasks.
